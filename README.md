# DevJobs - Plataforma de búsqueda de empleos

Plataforma web donde los desarrolladores pueden buscar ofertas de trabajo filtrando por título, ubicación, experiencia y tipo de contrato. Incluye paginación, página de detalle y diseño responsive.

## 🚀 Tecnologías utilizadas

- HTML5 semántico
- CSS3 (Flexbox, Grid, variables CSS)
- JavaScript (ES6+)
- Fetch API (consumo de datos desde JSON local)
- LocalStorage (para persistencia de datos)

## 🛠️ Funcionalidades

- Búsqueda en tiempo real por título
- Filtros combinados (tecnología, ubicación, experiencia, contrato)
- Paginación dinámica (5 resultados por página)
- Página de detalle con información completa del empleo
- Diseño responsivo (mobile first)
